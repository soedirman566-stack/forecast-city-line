# Rain, With Occasional Pauses for Heavier Rain

An entry for make.fun's **Funniest Forecast for a City That Isn't**: one
line, 114 characters, a weather forecast for the city of New Drowning,
where it has rained for so long that the drought festival is postponed
indefinitely.

> New Drowning: Rain, with occasional pauses for heavier rain. The drought festival has been postponed indefinitely.

## How it runs

`main.py` is the entrypoint. It reads the line from `line.txt`, checks it
against the competition gate (UTF-8 text, 1 to 120 characters), writes it
to `/output/entry.txt`, and reads the artifact back to prove it matches
the line exactly. It also prints the line to stdout.

## Files

- `main.py` — the entrypoint program.
- `line.txt` — the forecast line itself, exactly as judged.
- `LICENSE` — MIT.
